# Tank History

Website giới thiệu lịch sử phát triển của xe tăng từ Thế chiến II đến hết Chiến tranh Lạnh.

## Công nghệ
- HTML5
- CSS3
- GitHub
- GitHub Pages

## Cấu trúc
- `index.html`: Trang chủ
- `ww2.html`: Xe tăng trong Thế chiến II
- `cold-war.html`: Xe tăng thời Chiến tranh Lạnh
- `tank-types.html`: Các dòng xe tăng
- `css/style.css`: CSS dùng chung
- `images/`: thư mục để bổ sung hình ảnh
